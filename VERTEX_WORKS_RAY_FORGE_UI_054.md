# VERTEX WORKS 0.5.0
## VERTEX RAY — FORGE UNIFIED DARK UI / 000054

Purpose: make Project X-Ray / Scoped X-Ray visually belong to the same manufacturing facility as FORGE.

Design rules:
- darker than the previous Ray skin
- cyan used as signal/accent, not as a bright ambient wash
- near-black surfaces and restrained border contrast
- dense squared industrial controls
- terminal/evidence report surface
- Scoped X-Ray context menu and report overlay share the FORGE chassis language
- tolerant global Project X-Ray normalization selectors are included without mutating FORGE itself
- existing right-click, Scoped X-Ray, Vera handoff, Project X-Ray, and FORGE behavior remain intact
