# VERTEX WORKS — MAJOR REFINEMENT 000026

Status: SOURCE / BUILD / TEST PHASE

## Intent

This renovation does four things without collapsing every Vertex product into one color theme.

1. **Language policy**
   - Product/component/facility names remain English.
   - Global language selection is removed from Works UI.
   - Japanese is retained where it helps Human memory: Canonical Card content, origin, notes, and adoption flavor such as `採用`, `超採用！`, `超絶採用‼️`.
   - Machine semantics remain canonical English values.

2. **RAY / Project Relation Map**
   - Replace the "flat card listing" feeling with an interactive **Vertex Orbit Deck**.
   - Animated core at center.
   - Project cards orbit the core.
   - Mouse wheel rotates the orbit.
   - Clicking a non-front card rotates it to the front.
   - Clicking the front card selects/relays the underlying real project card when available.
   - No fabricated project names are introduced.

3. **RAY visual coherence**
   - Project Explorer folder cards and Analysis Findings use the same Works geometry, spacing, border/depth language.
   - Severity/state remains visually distinguishable.
   - "Same design language" does NOT mean "same color across Vertex products".

4. **Facility workspaces**
   - VXN / JUDGE / SENSOR / EVIDENCE / RELEASE receive real page shells now.
   - Pages explicitly display whether live source binding exists; they do not fake live data.
   - CANONICAL is exposed as a first-class REMEMBER facility and opens VCR.

## Theme rule

**Unify design language, not product identity color.**

Default theme:
- accent source = product icon/theme token.

Vertex theme:
- common optional Vertex brand theme included across Vertex products.

Works must not be recolored to imitate another factory-game palette.
Animation / depth / interaction ideas may be reinterpreted, but product color identity remains Works-owned.
